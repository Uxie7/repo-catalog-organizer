Repository Catalog Organizer

Scan repositories, review category and tag suggestions, then export a curated Markdown index. Nothing is published automatically.

1. Connect a public account or organization

For public repositories, leave the token blank. For private repositories, use a fine-grained token with read-only repository metadata and contents access. The token is held in this page's memory and sent only to this local app/GitHub; it is not saved by the app.
